# LLM_RAG v0.9.7 — Dialogue Intent & Definition Learning

## Purpose
v0.9.6 four-head MHA RoPE gave 2.390981 Test NLL compared to **2.348952** for single-head RoPE Medium. Chat dialogues still failed at '宇宙とは', '時間とは', '空間とは' and at resolving multi-turn references. This branch returns to **single-head RoPE Medium v0.9.5** and separates two hypotheses:

1. Does an intent-classification auxiliary loss improve the dialogue LM **beyond** equivalent extra SFT with no auxiliary loss?
2. Does a small *explicit definition-QA fine-tune* help on concept-definition prompts more than ordinary dialogue SFT? This is a tiny development demonstration, not a statistically credible factuality claim.

## Added
- `intent_model_v097.py` implements an auxiliary `d_model -> 7` intent classifier on the **last prompt token**, with causal masking preventing access to future answer tokens. Old model state tensors are preserved, new head has trainable weights. The standard `model.forward` and `generate` behavior remains unchanged.
- Labels: GREETING, DEFINITION, FACT_QUESTION, PREFERENCE, FEELING, REQUEST, OTHER; regex pseudo-labels only for high-confidence examples; unknown labels use `-100` and do **not** contribute intent loss.
- `train_intent_v097.py` implements `L_total=L_answer + lambda*L_intent` for `lambda=0` control and `lambda=0.2` experiment. Both start with **the identical v0.9.5 Medium trained backbone**, initialize the head with the same random seed, train on exactly the same 193,636 Real Persona Chat rows, and use the same validation split.
- `prepare_concepts_v097.py` builds a tiny, authored, subject-disjoint set of 20 train, 6 validation, 8 test definition QAs. No personal or private text.
- The existing `evaluate_real_dialogue_v082.py` accepts explicit `--baseline-intent`, `--tuned-intent` for compatible checkpoints.
- `chat.py` automatically loads intent-aux checkpoints; add `--show-intent` for an experimental prediction display. The predicted intent is not a correctness guarantee or knowledge gate.
- `tests/test_intent_v097.py` adds 20 tests covering classification, causal future-answer isolation, gradient flow, backbone preservation and concept split protection.

      --checkpoint model/model-rag-rope-medium-v0.9.5.pt `

      --max-train 0 --max-validation 0 --device auto `
      --output model/model-rag-intent-control-v0.9.7.pt `
      --report results/intent_control_train_v097.json

## 3. Experiment C — continued SFT PLUS auxiliary weak-intent loss
    python train_intent_v097.py `
      --checkpoint model/model-rag-rope-medium-v0.9.5.pt `
      --aux-weight 0.2 `
      --epochs 1 --batch-size 4 --learning-rate 0.00002 `
      --max-train 0 --max-validation 0 --device auto `
      --output model/model-rag-intent-aux-v0.9.7.pt `
      --report results/intent_aux_train_v097.json

**Do not compare auxiliary model only against v0.9.5** and attribute changes to intent; both A0 and C get an identical additional SFT epoch. Likewise, do not interpret the reported weak-intent accuracy as real generalization: the ground truth was generated by the same heuristic that trained the head.

## 6. Experiment B — small definition-SFT data (independent mechanism)
Generate a tiny, reviewable set of concepts, with *different target subjects* in train vs test:
    python prepare_concepts_v097.py --output-dir data/dialogue/concepts_v097

Train a **separate** copy of v0.9.5 Medium on 20 authored training answers, 6 validation answers:
    python train_real_dialogue_v082.py `
      --checkpoint model/model-rag-rope-medium-v0.9.5.pt `
      --source data/dialogue/concepts_v097/concept_train_v097.jsonl `
      --validation data/dialogue/concepts_v097/concept_validation_v097.jsonl `
      --max-train 0 --max-validation 0 --epochs 5 --batch-size 4 `
      --learning-rate 0.00002 --rope `
      --output model/model-rag-concepts-v0.9.7.pt `
      --report results/concepts_train_v097.json --device auto

Evaluate eight *different concepts* (including 宇宙, 時間, 空間):
    python evaluate_real_dialogue_v082.py `
      --baseline model/model-rag-rope-medium-v0.9.5.pt --baseline-rope `
      --tuned model/model-rag-concepts-v0.9.7.pt --tuned-rope `
      --test-data data/dialogue/concepts_v097/concept_test_v097.jsonl `
      --sample 8 --generations 8 --batch-size 4 `
      --output results/concepts_heldout_v097.json --device auto

The tiny concept dataset is a proof-of-mechanism. Its test subjects are excluded from the authored training and validation splits but may appear in the original Real Persona Chat pretraining or general language knowledge. The answers are brief simplified descriptions, not exhaustive definitions. This B experiment introduces extra task-specific data and optimization and is *not* controlled solely for auxiliary-loss effect. Do not compare it to C as if only intent supervision differed.

## Interpreting the results
- First: compare A0 vs C (same rows, init and training schedule) for answer-token Test NLL and actually generated responses.
- Second: compare B vs v0.9.5 on the eight authored subject-disjoint concept questions. Eight examples do not prove semantic understanding or generalization.
- Third: review whether responses to incomplete questions such as '貴方は' appropriately ask for clarification; current weak labels mask them and DO NOT implement an abstention gate.
- The 256-character-token window and character tokenizer are unchanged. Additional fine-tuning on tiny definitions can degrade casual chat. Preserve all v0.9.5 and v0.9.6 checkpoints.
- Private Real Persona Chat datasets and text-bearing reports remain local. No files are uploaded to GitHub by these scripts.
