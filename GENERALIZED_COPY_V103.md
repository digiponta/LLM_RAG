# LLM_RAG v0.10.3 — Generalized Copy Learning

## Why

v0.10.2 copied 16/16 TRAIN examples after 10 epochs, yet copied 0/8 DEVELOPMENT examples; NLL worsened from 4.712 to 5.651 on heldout data by epoch 40. This is memorization without demonstrated copying generalization. v0.10.3 adds diverse natural substrings and synthetic compositions to test learnable *copy rules* rather than memorization.

The same tokenizer, existing RoPE Medium (~2.1M parameters), 256-token context, prompt format and masked answer-token SFT trainer remain unchanged.

## 2. Prepare a diversified dataset

```powershell
python prepare_generalized_copy_v103.py `
    --width 10 `
    --train-count 2000 `
    --development-count 200 `
    --output-dir data/dialogue/copy_general_v103
```

- Training natural snippets come from v0.9.9 **Nagato TRAIN source lines**; development natural snippets come from v0.9.9 **Nagato VALIDATION source lines**. No original source line crosses these two splits.
- Synthetic 10-character strings are generated by independent deterministic random combinations of a **TRAIN-only character inventory**. The generated string sets are explicitly checked for disjoint answers.
- Natural snippets and synthetic combinations are interleaved; the report records their proportions and number of tokenizer-rejected samples. This retains a simple copying goal without substituting a fact-learning benchmark.
- **The original Nagato TEST file is never read** during dataset preparation or model training. Preserve it for final evaluation after selecting the procedure with development.

## 3. Continue SFT (development-gated best checkpoint)

```powershell
python train_real_dialogue_v082.py `
    --checkpoint model/model-rag-binding-v0.10.0.pt `
    --source data/dialogue/copy_general_v103/copy_general_train_v103.jsonl `
    --validation data/dialogue/copy_general_v103/copy_general_development_v103.jsonl `
    --max-train 0 --max-validation 0 `
    --epochs 5 --batch-size 16 --learning-rate 0.00005 `
    --rope --device auto `
    --output model/model-rag-copy-general-v0.10.3.pt `
    --report results/copy_general_train_v103.json
```

Unlike v0.10.2's intentional 16-sample overfit probe, the existing shared SFT trainer saves only when development NLL improves. If it prints 'No gain; checkpoint not written', do not run the following comparison with a nonexistent checkpoint. Inspect the training report first.

## 4. Evaluate unseen development strings

```powershell
python evaluate_generalized_copy_v103.py `
    --baseline model/model-rag-binding-v0.10.0.pt `
    --tuned model/model-rag-copy-general-v0.10.3.pt `
    --dataset data/dialogue/copy_general_v103/copy_general_development_v103.jsonl `
    --sample 0 --max-new-tokens 32 --device auto `
    --output results/copy_general_development_v103.json
```

The evaluator reports separate groups for **natural**, **synthetic**, and **all**. Measurements: exact match, first-token accuracy, prefix coverage, positional character accuracy, generated length. It compares both frozen models on the same examples, with greedy decoding and repetition penalty 1.0.

**Important controls:** In this first v0.10.3 stage, do not run the original Nagato TEST partition or merge the small-copy checkpoint into normal chat. A favorable 200-case development result is a **development result**, not an independently verified final test. Unseen natural excerpts and unseen synthetic strings should both improve before claiming generalization.

## Decisions

| Observation | Next investigation |
|---|---|
| Train NLL decreases, development NLL rises | Lower LR; reduce epochs; larger/varied source set; inspect duplicate patterns |
| Development NLL decreases, exact copying remains ~0 | First-token accuracy and termination; inspect actual generated text |
| Synthetic improves, natural does not | Source distribution and tokenizer/character coverage |
| Both natural and synthetic unseen copying improve | Lock hyperparameters, then run a **single** untouched final test; next extend from 10 to 30/50 characters |

### Limits

Every copy target is explicitly included in the input context. This is a copy-generalization task and proves neither source retrieval nor factual answering. Derived Nagato text can include fiction and opinions; no raw private Persona Chat or locally generated datasets should be committed to GitHub. The original v0.10.0 checkpoint is preserved; v0.10.3 is experimental, not a replacement production chat release.
